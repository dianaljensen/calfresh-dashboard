# Original Tableau Public dashboard — reference screenshots

Archived here so they persist as actual reference images for the Phase 4 rebuild, not just relied on from memory of having looked at them. All shared by Diana on 2026-07-29 (except the first, shared 2026-07-28), from her original Tableau Public workbook (SF-Marin Food Bank branding, San Francisco selected as the example county throughout).
