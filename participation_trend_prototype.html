Recreation of the original Tableau "ParticipationTrend" tab — working prototype, not final design

This is a first-pass working prototype, built to test feasibility, not a finished design. It's using a real snapshot of CDSS's Master dashboard file (downloaded 2026-07-16) rather than a live feed — the production version will fetch current data directly from the published Google Sheet instead. Colors are placeholders; we still owe this a dedicated conversation about using color meaningfully. Chart types and layout are the part meant to be judged here.
